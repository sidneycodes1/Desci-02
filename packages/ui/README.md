# @sciagent/ui

Glassmorphic dark design system for the SciAgent workspace: `Button`, `Card`,
`Badge` (project/milestone status), `Input`, `Modal`, `Spinner`.

Used by `apps/web`. No app logic here — presentational components only.

```bash
pnpm --filter @sciagent/ui test
pnpm --filter @sciagent/ui typecheck
```
